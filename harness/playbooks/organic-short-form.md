# Playbook: Organic social (TikTok, Instagram, YouTube, X, LinkedIn page)

Per platform:
- **Cadence:** posts/week and days since last post. 5+/week = a content machine (often a team or creators); <1/week = not an engine.
- **Reach:** median views (recent) vs followers. Median views far above followers = the algorithm is distributing them (hooks work). Top-video views far above median = hit-driven; study the hits.
- **Hooks:** quote the top 5 by views. Classify: POV skit, "I tried…", problem → solution, green-screen reaction, listicle, tutorial, founder vlog, trend/sound.
- **Format mix:** reels vs carousels vs images (IG); shorts vs long-form (YouTube).
- **Accounts that look like ads:** spark ads / paid partnerships inside the organic sample.
- **Faceless vs face:** if hooks read like characters/creators, they likely run UGC creators or a creator network (multiple accounts).
- **Company LinkedIn:** follower count and post cadence; most B2B reach comes from founders, not the page.

Copyable output: cadence target, the 3 hook templates to copy, and whether to use creators/UGC.
