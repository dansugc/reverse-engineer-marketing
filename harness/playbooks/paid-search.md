# Playbook: Paid search (Google, Microsoft, Apple Search Ads)

- Google Ads Transparency gives creative count, formats (text/image/video) and first/last shown dates per advertiser. "Shown in the last 30 days" means currently active.
- Text-heavy = search campaigns (high intent: brand defense, competitor terms, category terms). Image/video = Display / YouTube / Performance Max / Demand Gen.
- Multiple advertiser names pointing at one domain = affiliates, resellers or an agency bidding on the brand. That's either an affiliate channel or a brand-protection problem.
- A Google Ads conversion tag (AW-) without visible ads = spend paused, regional, or run under another advertiser entity.
- Microsoft UET tag = they bothered with Bing → usually B2B or older demographics.
- **Apple Search Ads** come from Apple's public Ad Repository (EU only, last 12 months): total ads, how many still serve, placements (search results / Today tab / Search tab), formats (Icon vs Icon + Asset), the subtitle each ad shows (App Store message testing in the open), countries, and whether they use audience targeting (age / gender / location / customer type). Thousands of ads across every EU market = App Store search is a core install channel. One message across all ads = they found a winner and stopped testing. Other apps with near-identical names advertising = copycats or brand bidders: say so, don't assume intent.
- **App Store links inside Meta/TikTok ads**: `ppid` = custom product pages (a tailored App Store page per audience or angle — mature app marketers do this), `ct`/`pt` = App Analytics campaign tokens (campaign naming), other params (e.g. `trybe`) = an attribution or partner tool. Report what's present; absence of `ppid` means every ad lands on the default App Store page.

Copyable output: whether to bid on own brand, competitor terms, and which format mix.
