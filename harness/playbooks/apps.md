# Playbook: Mobile apps

- **App Store:** rating count is a download proxy (very roughly 1 rating per 50–200 installs; say "proxy"). Rating average, first release date (age), update recency.
- **Description & release notes:** positioning, paywall/subscription wording, ASO keywords in the name/subtitle.
- **Google Play:** download band (e.g. 1M+).
- **Attribution SDKs** (AppsFlyer, Adjust, Branch, Singular) on the website = paid install campaigns are likely.
- **Apple Search Ads**: see the paid-search playbook — the EU Ad Repository gives real counts, messages and markets.
- **Typical consumer-app engine:** UGC/creator TikTok + Instagram content → Meta/TikTok install ads with the same hooks → paywall with trial. Check whether the evidence supports this or something else.

Copyable output: install channel mix, the hook style, and the paywall/trial pattern.
