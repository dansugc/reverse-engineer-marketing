# Playbook: Paid B2B (LinkedIn, Reddit, X) and app installs (TikTok)

- **LinkedIn:** ad types (single image, document/carousel, video, thought-leader ads, conversation ads), headlines, CTAs, targeting summary if exposed. Document ads / lead-gen forms = gated content funnel. Thought-leader ads (promoting a founder's post) = founder-led + paid hybrid.
- **Reddit:** the public ad library is gone; a Reddit pixel means they test or run Reddit ads. Pair with community evidence (which subreddits talk about them).
- **X:** X pixel = they ran or run X ads. The X ad repository is EU-only and manual.
- **TikTok:** no global ad API. TikTok pixel + app attribution SDK (AppsFlyer/Adjust/Branch) = likely TikTok install campaigns. Spark ads appear as "is_ads" on organic posts in the TikTok sample.

Copyable output: which B2B platforms are worth testing given their ICP, and the gated asset if they use one.
